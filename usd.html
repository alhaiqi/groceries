Kronor → Dollars

A one-click button for any Swedish shop: Coop, Willys, ICA, Lidl. It puts the dollar price next to every kronor price on the page, including the cart total.

38.73 SEK/pc≈ $3.80← what you'll see on coop.se

On a laptop (Chrome, Edge, Firefox)

  1. Show the bookmarks bar: Ctrl + Shift + B (Mac: ⌘ + Shift + B).
  2. Drag this green button onto the bookmarks bar:
    SEK → USD
  3. Open coop.se (or any shop), then click SEK → USD on the bookmarks bar.

Prices that load later, like more products or your cart, convert by themselves. Click it again after moving to a new page.

On an Android phone (Chrome)

  1. Bookmark this page (⋮ → ☆), then edit that bookmark: name it usd and replace its URL with the code below.
  2. On coop.se, tap the address bar, type usd, and tap the bookmark that appears (the one with the star).

iPhone Safari works the same way: save a bookmark, edit its address to the code, then open it from the bookmarks while on the shop's page.

How it works

It takes today's exchange rate from the European Central Bank (via Frankfurter). If a shop's site blocks that, it uses 1 kr ≈ $0.098 and says so in the message at the bottom of the page. Nothing is sent anywhere; it only changes what you see on your own screen, and refreshing the page removes the tags.

No bookmark handy? Divide kronor by 10: 85 kr ≈ $8.50.
