# Groceries — https://alhaiqi.github.io/groceries/

Weekly shopping list built from the meal plan (daily amounts × days). Items in the same group replace each other: mark one "Not available" and its share moves to the next item (tomatoes → cucumbers → carrots…). Edit amounts and the mix in **My plan**, add extra items in **Add item**, share the list as text. Installable and works offline; data stays in your browser.

Companion to [Gym Log](https://alhaiqi.github.io/gym/). Shortcut: Alt+Shift+F with the Gym Log Chrome extension.
